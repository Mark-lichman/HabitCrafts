## Origin and caveats

The codebase was generated by FlutterFlow and exported on 2026-07-26. Three consequences shape
everything documented here:

1. **`lib/flutter_flow/` is framework code, not application code.** It is FlutterFlow's runtime
   support layer, reproduced into every exported project. Treat it as a vendored dependency.
2. **`lib/custom_code/` is the only hand-written Dart.** 19 actions and 7 widgets. Defects
   concentrate here, because it is the code FlutterFlow neither generated nor validated.
3. **Entity counts come from a frozen snapshot.** `.flutterflow/export_manifest.json` records 188
   entities as of the export. It does not update as the code changes and will drift.

Now that the project has left FlutterFlow, the builder is no longer the source of truth. This
repository is.

## Scale

As of 2026-07-26: 304 Dart files, ~64,700 lines in `lib/`, 22 Firestore collections, 18 pages,
19 routes, 11 Cloud Functions, 80 components.

## Platform targets

iOS 14.0+, Android 9+ (`minSdkVersion 28`, target and compile SDK 36), and Flutter web. There are
no macOS, Linux, or Windows targets.

## No subscription model exists

HabitCrafts has no free or paid tier. There is no payment dependency in `pubspec.yaml`, no
entitlement field on any record, and no billing collection. `free_trial_screen_widget.dart` is a
675-line marketing screen reading "Try 7 Days for Free" that nothing navigates to.

This is recorded so nobody mistakes that screen for a working feature. Designing the model is
premature until there is something to sell.
