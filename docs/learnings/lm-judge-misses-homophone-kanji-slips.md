The independent judge pass applied its context-meaning rule and still missed `早{はや}く` for "swim
fast". The speed kanji 速 is outside N4, so that twin is plain はやく; an auditor caught it before land.
After any single-twin fix, grep the same reading in every draft, and scan homophone pairs such as
書/描, 買/勝, 行/言, 開/空, 早/速, 止/泊, 着/付, 借/貸.
